# Notes for specific blueprints

  ## Old Blueprints 
  I don't think any of these require mods. However, I'm not sure, and don't care to look.

  ## Ships Section 
  Speed Racer and awa require mod [K2 Fluid Storage](https://mods.factorio.com/mod/k2-fluid-storage).
  Flamewall Mk.2 and Aeternidas require mod [Nixie Tubes](https://mods.factorio.com/mod/nixie-tubes).
    
  ## Tumi Rails
  This design is based off of a design I found online months ago for city "bricks." There are no four-way intersections here, only three-way T junctions. It's a right-hand drive system which includes roboports and substations. To use, place two city block endcaps, then connect with the variety of straight rails in the book. It's designed for 1-4-1 trains, although it's definitely expandable to larger trains if necessary. The endcaps can be placed on top of straight rail segments. Included are an example block and a bot mall designed originally for Vulcanus but also usable on Nauvis. 

  ## Parameterized Mall
  Blueprints that automatically set up requester and storage chests. Parameterized so they're easily pastable. Has setups for Assembling Machine 3, Assembling Machine 2, Electromagnetic Plant, and Foundry. Also in the book is a parameterized upcycler. Should work with any assembly machine item, and can be arbitrarily stopped at any given rarity by deconstructing the higher rarity segments.

  ## Circuits
  Midgame circuit builds that do not require any tier 3 modules or quality.

  ## Vulcanus 120SPM
  All setups and all components to make at least 120 Metallurgic, Utility, and Production Science on Vulcanus. 192MW acid neutralization power plant is included. Also includes one of the wackiest thing's I've ever mashed together; a 1 -> 0.8 + 0.2 balancer.
    
  In the raw materials book, the blueprint "3 Blue Circuits/s" requires mod [Textplates](https://mods.factorio.com/mod/textplates). In the same book, the coal liquefaction setup requires mod [K2 Fluid Storage](https://mods.factorio.com/mod/k2-fluid-storage).
